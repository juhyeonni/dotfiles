# Claude Code

## Instructions

| Scope | Source | Deployed to | Applies to |
|-------|--------|-------------|------------|
| user | `home/dot_claude/CLAUDE.md` | `~/.claude/CLAUDE.md` | Every project |
| project | [`CLAUDE.md`](../CLAUDE.md) | — | This repo only |

Project instructions load later, so they win any conflict.

## What is managed

`~/.claude` holds config and over 500M of generated data in one directory. chezmoi writes only the
files tracked here and leaves the rest alone.

| Managed | Not managed |
|---------|-------------|
| `CLAUDE.md`, `settings.json` | `~/.claude.json` — OAuth token (outside the directory) |
| `skills/clear-draft` | `projects/` — conversation transcripts, stored in plaintext |
| `statusline-command.sh`, `subagent-statusline.sh` | `plugins/` — reinstalled from the list in `settings.json` |
| | `hooks/herdr-agent-state.sh` — generated by herdr |
| | `history.jsonl`, `file-history/`, `shell-snapshots/` and other caches |

Entries under `~/.claude/skills/` that link into `~/.agents/skills/` belong to another tool;
chezmoi leaves them alone.

## herdr hook

The SessionStart hook in `settings.json` runs `~/.claude/hooks/herdr-agent-state.sh`, which herdr
generates:

```bash
chezmoi apply
herdr integration install claude
chezmoi diff   # the installer adds a duplicate SessionStart hook; `chezmoi apply` removes it
```

Without the script, Claude Code warns about the hook and starts normally.

Claude Code rewrites `settings.json` itself. After changing settings inside Claude Code, run
`chezmoi re-add`.
