# Vimium

Link hint styling for [Vimium](https://github.com/philc/vimium) on Brave, in
`vimium/link-hints.css`. chezmoi does not deploy it: Vimium keeps its settings in the browser
profile, not in a file.

To apply: Vimium options page → paste `vimium/link-hints.css` into "CSS for link hints" → Save.

The copy goes both ways. After editing the CSS in the options page, paste it back into the repo
file.

Only the CSS is kept. Key mappings, search engines and exclusion rules stay in the browser.
